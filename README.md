# 电脑锁 (PCLock) — Windows 7 儿童电脑使用时长控制
思路来源于https://github.com/wplleo/kidslock

专为 Windows 7 电脑/一体机设计的家长控制程序。后台静默运行，按设定时长倒计时，到时自动锁屏；
孩子需**按设定题量连续答对题目**（默认 10 道，题量与连对数可配）才能解锁，家长也可用 **PIN 码**快速解锁。

## 功能对照

| 需求 | 实现方式 |
|---|---|
| 开机自启、开机即倒计时 | 首次运行自动创建"登录时运行、最高权限"的计划任务（无 UAC 弹窗）；倒计时从登录那一刻开始 |
| 后台默认运行 | 无窗口，仅托盘小图标；设置/退出均需家长 PIN |
| 定时锁屏 15/30/45/60/90/120 分钟 | 托盘设置里六档可选，默认 60 分钟；剩余 5 分钟和 1 分钟有气泡提醒 |
| 重启仍锁 | 锁屏标记和剩余时间写入注册表 `HKLM\SOFTWARE\PCLock`；锁屏状态下关机重启，开机后**立刻恢复锁屏**；正常使用中重启不清零剩余时间，且**断电/关机期间的时长会折算扣除**（详见防作弊设计） |
| 解锁答题 | 全屏锁屏界面按设置的**年级（1-6 年级）/ 学科（语文·数学·英语·混合随机）**出题，**一次共 10 道互不重复的题，全部答对才能解锁**；数学为口算填答案，语文为"看词语选拼音"（附词语释义），英语为"看单词选汉语 / 看汉语选单词"（四选一）；答错任意一题则全部清零、等 5 秒从第 1 题重新开始 |
| 家长 PIN | 锁屏界面右下角"家长入口"，输入 PIN 直接解锁；默认 **1234**，可在设置中修改为 **4-12 位数字/字母/特殊符号组合**（不含空格） |
| 卸载需要密码 | 系统中没有任何"添加/删除程序"卸载入口；只能通过"设置 → 卸载并删除程序"，需要单独的**卸载密码**（默认 1234，可改为 4-12 位数字/字母/特殊符号） |
| 任务管理器不能杀进程 | 双重防护：① 进程 DACL 拒绝 `TERMINATE` 权限，任务管理器/taskkill 结束进程时提示**拒绝访问**；② 主程序与看门狗两个进程互相守护，任何一个被杀，另一个 3 秒内把它重新拉起并恢复锁屏。锁屏期间还写入系统策略**禁用任务管理器** |

## 防作弊设计

- **改系统时间没用**：正常倒计时直接递减剩余秒数，与系统时间无关；断电折算用的 UTC 时间戳只减不增，时钟回拨无法获利（回拨系统时间本身就需要管理员权限）。
- **直接断电（拔电源/遥控关机）也没用**：剩余时间每 15 秒连同 UTC 时间戳持久化，下次开机按时间戳扣除离线期间的时长，扣到 0 则开机即锁屏。因此「每次可用时长」实际按**日历时间**消耗——隔夜关机会扣掉隔夜时长；家长通过设置里「退出程序」正常退出时，剩余时间重置为完整时长。
- **关机重启没用**：剩余时间和锁屏状态每 15 秒持久化，重启后接着算。
- **Alt+Tab / Win 键 / Ctrl+Esc 被屏蔽**：锁屏期间通过低级键盘钩子拦截；锁屏窗口全屏置顶、覆盖所有显示器、无法关闭（Alt+F4 无效）。
- **答错清零**：10 题中答错任何一题，进度全部清零并从第 1 题重新开始，题目用完自动去重，防止碰运气刷题。
- **结束进程没用**：DACL 拒绝结束 + 看门狗互相拉活 + 锁屏期间任务管理器被策略禁用。

## 编译

把整个 `pclock` 文件夹拷到目标机器，双击 `build.bat`。
`build.bat` 优先调用 **.NET Framework 4.x** 自带的编译器，产物 `PCLock.exe` 面向 .NET 4.0 运行时，在装有 .NET 4.0+ 的 Win7 上即可运行（如系统未带 4.x，请先安装 .NET Framework 4.x）。
产物目录同时包含 `PCLock.exe.config`（声明支持的运行时），须与 `PCLock.exe` 放在同一目录。
构建前会自动生成 `src\_Version.cs`：**版本号每次构建自动取自 git tag**（去掉 `v` 前缀；GitHub tag 构建用 `GITHUB_REF_NAME`，本地取 HEAD 上的 tag，否则取版本最高的 tag；无 tag / 无 git 回退 `1.0.0`），Commit 取 git 短哈希。脚本为 `gen_version.bat`，`build.bat` 与 VS（`PCLock.csproj` 的 `BeforeBuild`）共用，无需手工改版本号。
单元测试：双击 `tests\run.bat`（同样基于系统自带 `csc`，零依赖），覆盖时段解析、题库组合与题库边界、PIN 哈希、数学答案一致性、断电折算、日志保留与统计键清理、错题库混入去重、多题库文件解析（116 项）。

## 安装（只需一次）

1. 在 C 盘建目录，如 `C:\Program Files\PCLock\`，把 `PCLock.exe` 和 `PCLock.exe.config` **一起**放入（两者必须同目录，路径建议固定，以后不要挪动）。
2. 右键 `PCLock.exe` → **以管理员身份运行**。程序会自动：
   - 创建开机自启计划任务（`schtasks` 名为 `PCLock`，最高权限、登录即启动、无 UAC 弹窗）；
   - 初始化默认设置（60 分钟、家长 PIN 1234、卸载密码 1234）；
   - 开始倒计时。
3. 之后每次开机登录都自动开始倒计时，无需任何操作。

## 日常使用（家长）

- 托盘小盾牌图标双击 → 输入家长 PIN → 设置窗口：
  - 选六档时长并保存（本次剩余时间重置）；
   - 修改家长 PIN、修改卸载密码（建议第一时间改掉默认 1234）；
  - 立即锁定 / 退出程序 / 卸载并删除程序（需卸载密码）。

## 行为日志（按天记录）

程序会在所在目录的 `logs\` 下按天生成日志文件（如 `logs\2026-11-03.log`），自动记录：

- 家长密码 / 卸载密码的验证成功与失败（只记结果，不记密码明文）
- 锁屏开始时间、结束时间、解锁方式（答题 / 家长密码 / 时段自动）及本次锁屏时长
- 设置修改（时长、年级科目、可用时段、密码修改、暂停/继续、加时）
- 程序启动、正常退出、卸载

> `err.txt` 仅用于异常与诊断信息，与行为日志相互独立。

## 卸载

托盘 → 设置（家长 PIN）→ **卸载并删除程序** → 输入卸载密码。
程序会自动删除计划任务、注册表配置和全部文件。

## 忘记密码怎么办

程序内置两个独立密码：**家长 PIN**（解锁/进设置）和**卸载密码**（卸载时校验），二者互不影响。

### 只忘记卸载密码（仍记得家长 PIN）

直接进入设置：托盘 → 输入家长 PIN → 「修改卸载密码」，设一个新密码即可（无需输入旧卸载密码）。

### 忘记家长 PIN（进不去设置）

没有内置找回功能，且程序自保护（拒绝 `taskkill`、看门狗会重启主程序），需由 **Windows 管理员** 清理配置恢复。以管理员命令提示符执行：

```bat
:: 1) 删除开机自启（程序只在启动时创建一次，删除后不会自建）
schtasks /delete /f /tn PCLock
:: 2) 删除 HKLM Run 回退项（无该项会提示找不到，忽略即可）
reg delete "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v PCLock /f
```

重启电脑（受保护进程需重启才会停止，且开机不再自启），然后：

```bat
:: 3) 删除程序配置（含两个密码哈希、锁屏标记等）
reg delete "HKLM\SOFTWARE\PCLock" /f
```

之后二选一：

- **继续使用**：以管理员身份重新运行一次 `PCLock.exe`，会重新初始化，家长 PIN 与卸载密码都恢复为默认 **`1234`**（请随后立即修改）。
- **彻底移除**：直接删除程序文件夹。

> 该通道依赖 Windows 管理员权限，因此请给孩子使用"标准用户"账户，并保管好管理员密码（详见「安全边界」）。

## 安全边界（请务必阅读）

没有绝对不可破解的防护，以下是已知边界和推荐用法：

1. **强烈建议：孩子使用"标准用户"账户，家长管理员账户设置 Windows 密码。**
   这样孩子无法提权，任务管理器/注册表/删除文件都动不了本程序，防护最牢固。
2. **Ctrl+Alt+Del 无法屏蔽**（Windows 安全序列）。锁屏界面下任务管理器已被禁用；
   若孩子注销，重新登录后程序随开机自启立刻恢复锁屏。请勿让孩子知道任何 Windows 账户密码。
3. **安全模式**：开机狂按 F8 进入安全模式时计划任务不启动，孩子可用电脑但依然无法删除程序文件或注册表（标准用户无权限）；退出安全模式正常开机后锁屏状态恢复。
4. 若孩子使用的是**管理员账户**且知道密码，可手动结束进程/删注册表——任何软件都无法完全防住知道管理员密码的人。请管好管理员密码。
5. 程序编译后建议在真机 Win7 上完整验证一遍：倒计时到点锁屏、答完 10 题解锁、PIN 解锁、锁屏中重启恢复、任务管理器结束进程被拒绝。

## 本副本修复记录（相对上游）

### Bug 修复

1. **(2026-09-30) 气泡提醒因 Timer 精度漂移可能跳过**（`App.cs`）
   原代码用 `remaining == 300` / `remaining == 60` 精确匹配，Timer 精度可跳过中间值。
   改为 `remaining <= 300` / `remaining <= 60` 范围判断 + `warned5` / `warned1` 标志位防重复，
   在 `Unlock()` 和 `ResetRemaining()` 中重置标志。

2. **(2026-09-30) 计划任务 `/TR` 参数多前导反斜杠**（`App.cs`）
   原代码 `schtasks /TR "\" + exe + "\\"` 生成了 `\\C:\...\PCLock.exe\\`，
   `schtasks` 不接受多前导 `\`。去掉多余转义，现在正确生成 `/TR "C:\Program Files\PCLock\PCLock.exe"`。

3. **(2026-09-30) UnprotectSelf 安全描述符结构错误**（`Protection.cs`）
   原代码构造 20 字节 SD 并设 `SE_DACL_PRESENT`，但 ACL 数据不存在，`Dacl` 偏移无效。
   改为 28 字节（20 header + 8 字节空 ACL），正确设置 Dacl 偏移=20、ACL_REVISION=2、ACE 数=0。

4. **(2026-09-30) 口算题可能凑不齐指定数量**（`MathUtil.cs`）
   `NextBatch(count)` 中 2000 次循环用尽后直接返回，可能少于 count 道。
   增加兜底 while 循环：不重复抽完后再允许重复，保证返回数量恒等于 count。

5. **(2026-09-30) 看门狗日志用相对路径**（`Watchdog.cs`）
   原代码 `File.WriteAllText("watchdog_log.txt", ...)` 写到当前工作目录。
   改为 `AppDomain.CurrentDomain.BaseDirectory + "watchdog_log.txt"`，确保写入 EXE 同目录。

6. **(2026-09-30) 看门狗 while 循环内 GetLockFlag 无异常保护**（`Watchdog.cs`）
   `Store.GetLockFlag()` 可能因注册表异常抛出，直接放在 `if` 条件里会导致 while 异常退出。
   先 try-catch 到局部变量 `flag`，再用 `flag == 1` 判断。

7. **(2026-09-30) PIN 对话框无全局冷却机制**（`SettingsForm.cs`）
   反复打开→失败 5 次→关闭→重开，可无限尝试。增加 `static cooldownUntil`，
   5 连败后全局 30 秒冷却，跨对话框实例生效。

8. **(2026-09-30) PIN 密码无长度上限**（`SettingsForm.cs`、`LockForm.cs`）
   仅校验 `>=4` 位，无上限。三个 PIN 输入框均增加 `MaxLength = 20`。

9. **(2026-09-30) 锁屏界面未拦截 Shift+Tab**（`LockForm.cs`）
   原代码只检查 `alt` 键拦截 Alt+Tab，Shift+Tab 可绕过。
   改为分别处理 `WM_SYSKEYDOWN`（Alt+Tab）和 `WM_KEYDOWN + shift`（Shift+Tab）。

10. **(2026-09-30) 钩子回调 P/Invoke 函数未声明**（`LockForm.cs`）
    原代码调用 `GetKeyState` 但无 `[DllImport]` 声明（编译必失败）。
    改用已声明的 `GetAsyncKeyState`（low-level hook 中更可靠，不依赖线程输入队列），
    删除多余的 `GetKeyState` 声明。

11. **(2026-09-30) 锁屏 PIN 框允许输入非数字字符**（`LockForm.cs`）
    答案框只接受数字，PIN 若包含字母则永远无法匹配。增加数字字符过滤。

### 自定义题库（外部文件）

语文、英语题库支持外部文件，家长可自行增删，**无需改代码、无需重新编译**。

- **文件位置**：程序所在目录下的 `chinese.txt`（语文）、`english.txt`（英语）。
- **加载规则**：程序启动时优先读取这两个文件；**若文件缺失或内容为空，则自动回退到程序内置兜底题库**（`src/ChineseData.cs`、`src/EnglishData.cs`），保证永远有题可答。
- **格式（每行一条，`|` 分隔）**：
  - 语文 `chinese.txt`：`年级|词语|拼音|释义`
  - 英文 `english.txt`：`年级|英文单词|中文意思`
  - 以 `#` 开头的行是注释、空行会被忽略；年级填 `1~6`；拼音用空格分隔各字读音（如 `tài yáng`）。
  - 示例：
    ```
    # 语文题库（可自由增删）
    1|太阳|tài yáng|恒星，白天发光发热的天体。
    3|勇敢|yǒng gǎn|不怕危险和困难，有胆量。
    ```
- **编辑注意**：保存时请选择 **UTF-8 编码**（Windows 记事本「另存为」→ 编码选 UTF-8），否则中文可能乱码。
- **多题库（按教材 / 单元拆分）**：在程序目录下建 `banks\` 子目录，每个 `.txt` 是一个题库，**文件名即「题库名」**，可在「高级规则 → 学期 / 题库名过滤」里只抽某一册的题。文件内可用头部给出默认值，减少逐行重复：
  ```
  #grade:3
  #term:上
  #bank:PEP三上
  春天|chūn tiān|季节名
  瀑布|pù bù|水名|下|自定义
  ```
  块头 `#grade/#term/#bank` 提供默认值；行内写了对应列则以行内为准；不带年级列的行沿用块头年级。`chinese.txt` / `english.txt` 仍会一起加载（旧配置无需改动），三处都没有时才回退内置题库。
- **多科均派**：同时选中多个科目时，各科目**轮转均派**（10 题三科约 4/3/3），避免偏科刷屏；只选一科时全部为该科题目。

### 每日可用时段 & 按用户分别限制

电脑锁支持**按 Windows 登录用户分别设置**使用时长与可用时段，并支持**每日可用时段**（时段外强制锁屏）。

#### 按用户分别限制
- 在家长设置窗口顶部「**配置对象（Windows 用户）**」下拉框中选择要设置的账户（列出所有已配置用户 + 当前用户）。
- 选中的用户会**独立保存**：每次可用时长、每日可用时段、今日已用统计都互不影响。
- 例如：哥哥账户每天 60 分钟、时段 08:00-21:00；妹妹账户每天 30 分钟、时段 09:00-20:00。各算各的，互不干扰。
- 程序以「当前登录的 Windows 用户」为准读取对应配置；为其他用户配置后，**需该用户下次登录时才生效**（改当前用户时长会立即重置本次剩余时间）。

#### 每日可用时段
- **位置**：家长设置窗口「**每日可用时段（按用户）**」文本框。
- **格式**：`08:00-12:00;14:00-21:00`（每段 `起始-结束`，多个时段用**分号/逗号**分隔；**留空 = 全天可用**；起始大于结束时按**跨午夜**处理，如 `22:00-06:00` 表示仅夜间可用）。
- **效果**：
  - 不在允许时段内时，电脑会被**强制锁屏（硬锁）**——不计时、不扣时长，孩子无法靠答题解锁。
  - 锁屏界面仅保留「家长入口」PIN 解锁（家长可破例放行）。
  - **时段开始后自动解锁**，并开始新一轮计时；无需家长每次干预。
  - 家长在设置中「暂停计时」可临时突破时段限制（暂停期间不检测时段）。
- **容错**：非法时段（如 `25:00`）、缺横杠、空段都会被忽略；解析不到任何有效段时视为「全天可用」。

### 2026-10-05 — v1.5.0 (代码审查修复：正常关机识别、自启引号、PIN 加固等)

#### 🐛 Bug 修复

1. **(2026-10-05) 正常关机/重启后下次开机会按离线时长整段扣除剩余时间** (`App.cs`)
   - **根因**：v1.4.0 的 30 秒阈值只能挡住"关机过程延迟"。`App.Shutdown()` 只在设置窗口的"退出程序/卸载"时调用，开始菜单的正常关机/注销走不到，`LastSeenUtc` 未清除，下次开机 `DeductOffline` 把整个关机时长扣掉 → 剩余归零 → 开机即锁屏
   - **修复**：订阅 `SystemEvents.SessionEnding`，正常注销/关机时保存剩余时间并写 `LastSeenUtc=0`；硬断电收不到该事件，仍会正确扣除。若关机被其他程序取消，`OnTick` 会在 15 秒内重新写回时间戳
2. **(2026-10-05) 安装路径含空格时开机自启静默失效** (`App.cs`)
   - **根因**：`schtasks /TR` 的值含空格时会在第一个空格处被拆分（任务动作变成 `D:\Program` 之类），且 schtasks 仍返回成功；原代码只包了一层外引号，未做内层引号转义
   - **修复**：`/TR` 参数改为 `/TR "\"路径\""` 形式，路径被内层引号完整保护
3. **(2026-10-05) 答错/PIN 冷却实际只有显示秒数的一半** (`LockForm.cs`)
   - **根因**：`uiTimer` 每 500ms 触发一次，却直接对以秒为单位的 `wrongLeft`/`pinCooldown` 做递减，"5 秒"实际 2.5 秒、"30 秒"实际 15 秒，倒计时显示也以双倍速度跳
   - **修复**：冷却改用 `Environment.TickCount` 按真实时间每 1000ms 递减一次，保持全屏/焦点定时器仍为 500ms
4. **(2026-10-05) 设置含字母的 PIN 后锁屏界面永远输不进去** (`SettingsForm.cs`)
   - **根因**：设置窗口的 PIN 输入框不过滤字符，而锁屏"家长入口"输入框只接受数字
   - **修复**：设置窗口与 `PinDialog` 的输入框统一只接受数字，与锁屏界面一致
5. **(2026-10-05) 卸载瞬间的竞态可能留下"任务管理器被永久禁用"的注册表残留** (`App.cs`)
   - **根因**：`Shutdown(true)` 期间 Timer 仍在跑（内部有最长 5 秒的 schtasks 等待），若 `remaining` 恰好递减到 0 会再次触发 `LockNow`：在 `RemoveAll()` 之后重建注册表键、写入 `LockFlag=1` 和 `DisableTaskMgr=1`，进程随即退出无人清理

## 0. 最近一次事故与修复（2026-11-11，v1.6.5）

- **现象**：v1.6.4 锁屏界面点任意选项按钮抛 `NullReferenceException`（`err.txt` 记 `UI THREAD EXCEPTION ... LockForm.OnOptionClick`），孩子点了没反应，看门狗反复重启主程序。
- **根因**：首题在 `LockForm` 构造函数里渲染，此时窗体尚未 `Show`；WinForms 中子控件 `Visible` getter 在父窗体不可见时恒返回 `false`。第三批「支持 2-4 选项」写成了 `if (optBtns[i].Visible) { 写 Text/Tag }`，判断永不成立 → 按钮无文字、`Tag` 为 `null` → 点击 `(int)null` 拆箱抛空引用。
- **修法**：新增 `src/UiSafe.cs`（`OptionIndex` / `ShowOption` / `OptionCount`），渲染按「实际选项数量」判断，点击统一走 `UiSafe.OptionIndex`，非法下标直接忽略；`PracticeForm` 同步修复；`restLabel.Visible` / `continueBtn.Visible` 改为字段与无条件恢复。
- **防复发**：`tests\gate.bat` 5/5 守卫——`src\**\*.cs` 出现非注释行 `if (xxx.Visible)` 即失败（已用可编译样例注入验证会拦下）。
- **教训**：UI 构造期一切「控件可见性」读取都不可信；同理 `Enabled`/`Focused` 也不要当状态位，用字段。

## 4. 明确的边界与不做的事

详见 [`能力边界与不做什么.md`](能力边界与不做什么.md)。要点：不阻止管理员绕过、
不屏蔽 Ctrl+Alt+Del、不联网不收集数据、不做应用锁/上网管理、答题不是学业测评。

**暂缓**：自动升级（需引入联网、独立 updater 进程、签名与回滚，触碰防作弊高风险区）。
**不采纳**：扫码局域网 Web 管理、AI 批改/在线题库、LaTeX/手写/语音、TV 虚拟键盘、
大人/儿童开机双选、ADB 外部看门狗自愈。
**不改**：DACL 字节布局、答错清零、PBKDF2 25000、UTC 折算与 30 秒阈值、500ms 置顶。


## 6. 版本与发布

- `gen_version.bat` 每次构建自动取 git tag 生成 `AppVersion.Version`（`v1.6.1` → `1.6.1`），
  CI tag 构建用 `GITHUB_REF_NAME` 优先，本地取 HEAD tag 或版本最高 tag，无 tag 回退 `1.0.0`。
- 打 `v*` tag → `release.yml` 编译 `PCLock-Release.zip`、生成 `SHA256SUMS.txt`，一并上传并创建 GitHub Release。
- 历史遗留：Release `v1.6.0` 的 exe 由旧脚本编译，内部版本显示 `1.0.0`；
  新 tag 重新编译后即正常。

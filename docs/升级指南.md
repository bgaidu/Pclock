# PCLock 升级指南（手动替换 · 不用卸载）

> 适用：v1.5.0.x 及以上手动安装（把 `PCLock.exe` 放进固定目录）的机器。
> 当前最新版本：**v1.6.3**（2026-11-11）。
> 自动升级功能**尚未实现**（见 `能力边界与不做什么.md`），升级＝下载新 exe → 退出旧程序 → 替换文件 → 重新启动。

## 0. 先确认现在装的是哪个版本

托盘图标右键 → **设置…（需家长PIN）** → 菜单栏 **关于**，窗口标题下方会显示 `电脑锁 v1.6.3 (9ef6d2b)`。

也可以直接右键 `PCLock.exe` → **属性 → 详细信息**，看「文件版本」（如 `1.6.4.0`）与「产品版本」（如 `1.6.4+3fd3436`）。

> 说明：文件版本属性自 **v1.6.4** 起写入；更早版本的程序集没有版本信息，只能用「关于」窗口确认。

## 1. 下载

GitHub Releases 页面 → 最新版本（`v1.6.3`）→ 下载 **`PCLock-Release.zip`**（约 430 KB）。
解压到临时目录，包里含：`PCLock.exe`、`PCLock.exe.config`、`AppIcon.ico`；若包里还有 `chinese.txt` / `english.txt`，先不要用它们覆盖自己的题库。

## 2. 备份（1 分钟，强烈建议）

把整个安装目录（如 `C:\Program Files\PCLock\`）复制一份为 `PCLock-backup-日期`。需要保留的自建数据：

| 文件 / 目录 | 内容 | 是否覆盖 |
|---|---|---|
| `chinese.txt` / `english.txt` | 自建语文/英语题库 | **不要覆盖** |
| `banks\` | 多题库（按教材/单元拆分） | **不要覆盖** |
| `logs\` | 行为审计日志 | 不要删 |
| `review-<用户名>.json` | 错题缓存 / 间隔重复 | 不要删 |
| `PCLock.exe` / `PCLock.exe.config` | 程序本体 | **要替换** |

家长 PIN、时长、时段、额度、加练池等都存在注册表 `HKLM\SOFTWARE\PCLock`，替换文件不会动它们。

## 3. 退出旧程序（必须，且只能用程序自己的出口）

托盘图标右键 → **设置…（需家长PIN）** → 底部 **退出程序** → 确认「是」。

- **不要用任务管理器结束进程**：程序给自己加了 DACL 拒绝结束，还被看门狗互相守护，强杀会导致残留进程或自启异常。
- **不要用「卸载并删除程序」**：那条路会清空注册表配置、删除计划任务和整个目录，等于重装。
- 如果当前正处于锁屏：先输入家长 PIN 解锁，再走上面的退出流程（锁屏状态下设置窗口会被顶到后面）。
- 退出后剩余时间会重置为完整时长，这是既有语义（「下次开机自动重新开始」），不是 bug。

## 4. 替换文件

在安装目录里用新包中的以下文件覆盖旧文件（需要管理员权限，UAC 会弹一次）：

```
PCLock.exe
PCLock.exe.config      （若旧版本也有，一并替换）
AppIcon.ico            （可选，换图标）
```

安装目录路径**不要改**：开机自启的计划任务（`schtasks` 名 `PCLock`）指向这个固定路径，换目录会失去自启。

## 5. 启动并验证

右键 `PCLock.exe` → **以管理员身份运行**（启动时会幂等重建自启计划任务，无需手动配置）。

验证清单：

- [ ] 「关于」显示新版本号（如 `v1.6.4 (xxxxxxx)`）
- [ ] 右键 `PCLock.exe` → 属性 → 详细信息，「文件版本」与 tag 一致（如 `1.6.4.0`）
- [ ] 家长 PIN / 卸载密码仍可用（注册表配置保留）
- [ ] 锁屏答题正常：答错清零 + 5 秒冷却 + 显示正确答案
- [ ] 「高级规则」「使用记录」能打开；新增功能默认关闭，行为与升级前一致
- [ ] 若自建了题库：抽题仍来自自己的词条（说明 `chinese.txt` / `banks\` 未被覆盖）
- [ ] 退出后重新登录 Windows，程序自动启动且无 UAC 弹窗（计划任务有效）

## 6. 回滚

把备份目录里的 `PCLock.exe` 与 `PCLock.exe.config` 拷回安装目录即可。配置在注册表，回滚不会丢数据；
若新版本改过配置项，旧版本会忽略不认识的键，不影响使用。

## 7. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 覆盖时提示「文件正在使用」 | 旧程序还在跑：重复第 3 步，确认托盘图标消失后再替换 |
| 替换后双击没反应 / 秒退 | 没以管理员身份运行（需要 HKLM 写权限），右键以管理员身份运行 |
| 开机不自启 | 计划任务被删或路径变了：以管理员身份运行一次程序会自动重建；也可 `schtasks /Query /TN PCLock` 检查 |
| 升级后要求重新设置密码 | 只发生在很老的安装（`PinSetupDone=0`）；按提示设置即可，旧 PIN 不再生效 |
| 想确认题库是否被覆盖 | 对比文件修改时间；或看「高级规则 → 题库与记录」里的题库名列表是否包含自己的 `banks\` 名 |

## 8. 以后会不会自动升级

暂缓（见 `docs/能力边界与不做什么.md`）：需要引入联网检查、独立 updater 进程、签名与回滚机制，
且替换自身会触碰 DACL / 双进程守护这套防作弊核心。当前方案是「家长手动替换」，风险最低。

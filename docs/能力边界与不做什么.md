# PCLock 能做什么 / 不能做什么

> 借鉴 PoHW 的「诚实边界」写法。本文与 `README.md` 的「安全边界」一起构成对外口径；
> 新增功能（P0/P1）默认关闭，未启用的能力不应被写进宣传语。

## 能做什么

- 按 Windows 登录用户分别限制**每次可用时长**、**每日总时长上限**、**每日解锁次数上限**。
- 按每日时段或多规则（星期 + 时间窗 + 跨午夜）管控；「仅时段内可用」时段外硬锁，
  「仅时段内需要答题」时段外自由使用、不扣时长（适合网课 / 家人共用时段）。
- 到点全屏锁屏，答题达标或家长 PIN 解锁；答错仍**整批清零 + 5 秒冷却**，并展示正确答案与解析。
- 累计答错达到阈值自动增加**加练题**，跨天 / 重启保留，答对逐道扣除，未清完不能解锁。
- 时长用尽后进入**护眼强制休息**（UTC 截止时间，重启不失效），家长可 PIN 解锁或**临时放行 N 分钟**。
- 按题目年级 / 难度给 **1–5 星时长奖励**（默认关闭），单次奖励上限 1 小时。
- **练习模式**：自由答题、即时反馈与统计，不解锁、不重置倒计时、不消耗额度。
- 题库支持 `chinese.txt` / `english.txt`（UTF-8）与 **JSON 导入导出**；内置题库质量门禁
  （题量、选项合法性、正确答案下标、占位符、题干去重、年级不超纲）。
- **7 天使用记录**柱状图与 CSV 导出；按天行为审计日志 `logs\yyyy-MM-dd.log`。
- 可选**时间回拨主动检测**（默认关闭），大幅回拨时保护性锁定，需家长 PIN 解除。
- 防绕过：进程 DACL 自保护、双进程互守护、锁屏禁任务管理器、低级键盘钩子、
  全屏置顶抢焦点、屏蔽系统命令、UTC 断电折算 + 重启仍锁。
- 工程化：零第三方依赖、零网络调用、99 项单测（含 5 项负向变异回归）、
  `tests\gate.bat` 一键门禁、tag 发布构建产物时间戳校验、可选发布证书指纹校验；
  GitHub 上仅打 `v*` tag 才编译，PR / 手动只跑单测。

## 不能做什么

- **不阻止管理员绕过**：孩子若使用管理员账户且知道密码，仍可结束进程、删计划任务 / 注册表、
  进安全模式或用 PE 启动。请给孩子使用「标准用户」账户并保管好管理员密码。
- **不屏蔽 Ctrl+Alt+Del**：Windows 安全序列；靠锁屏禁任务管理器 + 重新登录即恢复锁屏兜底。
- **不联网、不收集数据**：没有云端账号、遥测、远程管理、在线题库源或 AI 批改；
  所有配置与记录都在本机（HKLM 注册表 + 程序目录）。
- **不提供手机扫码 / 局域网 Web 管理**：Windows 上家长就在本机，引入监听端口只会增加攻击面。
- **不是应用锁 / 上网行为管理**：不阻止孩子使用其他设备，也不限制具体软件或网站。
- **答题不是考试测评**：题目由本地算法 / 词库生成，难度分档与星级只是奖励权重，不代表学业水平。
- **不保证绝对的时间正确性**：倒计时按剩余秒数递减，与系统时间无关；断电折算依赖 UTC 墙钟。
  离线不足 30 秒视为正常关机不扣除，这是已知设计取舍（需物理断电能力才能利用）。
- **练习模式不是解锁通道**：计时器照常运行，练习不会暂停或重置倒计时。
- **时间回拨检测默认关闭且有 5 分钟容差**：NTP 校时与家长手动微调不应触发误报；
  开启后主动大幅回拨才会锁定，不能替代账户权限管理。

## 新增功能的兼容约定

1. 旧安装（无 `PinSetupDone` 值）默认视为「已完成首次密码设置」，**升级不会强制改密**；
   仅新安装首次运行时强制设置家长 PIN 与卸载密码（且不能用默认 1234）。
2. 所有新增规则默认关闭或保持旧值：每日额度 0、解锁上限 0、多规则串空（沿用旧 `Win`）、
   题量 10 / 需连续答对 10、加练阈值 0、休息 0、星级奖励关、练习模式关、回拨检测关。
3. 答错反馈默认开启，但**不改变解锁判定**（仍整批清零、5 秒冷却）。
4. 多规则串为空时，`Store.IsWithinWindow` 旧解析与 11 项旧单测行为完全不变。

## 一、项目概述

PCLock（"电脑锁"）是一个面向家长的 Windows 使用时长管理程序。它常驻托盘运行，按"每个 Windows 用户"分别限制每日可用时长与可用时段；时间到点或不在允许时段内即进入全屏锁屏，孩子需答对题目或由家长输入 PIN 才能解锁。程序通过进程自保护、看门狗守护、禁用任务管理器、低级键盘钩子、强制置顶等手段防止被轻易绕过。

**技术栈与运行环境**

| 项 | 说明 |
|---|---|
| 语言/框架 | C# / .NET Framework WinForms（兼容 C#5 语法） |
| 编译方式 | 直接用系统自带 `csc.exe`（.NET 4.x）编译，零第三方依赖 |
| 运行依赖 | 需安装 .NET Framework 4.0 及以上 |
| 支持系统 | Windows 7 / 8 / 8.1 / 10 / 11 |
| 权限 | 需管理员权限（清单 `requireAdministrator`，写 HKLM/策略、计划任务） |
| 架构 | 主程序（托盘常驻）+ 看门狗进程（`--watchdog`）双进程协作 |

## 二、功能特性总览

- **使用时长限制**：按用户分别设置，可选 15/30/45/60/90/120 分钟（默认 60）。
- **每日可用时段**：按用户分别设置，支持多段（如 `08:00-12:00;14:00-21:00`），留空=全天。
- **锁屏答题解锁**：每次锁屏 10 题，全部答对方可解锁；答错则整批清零重来并冷却 5 秒；也可由家长输 PIN 解锁。
- **科目多选 + 年级多选**：科目（语文/数学/英语）与年级（1~6）都可多选；**选中科目的题会覆盖选中的年级范围**。
- **分年级数学题**：严格按小学各年级课标计算要求生成，答案恒为整数（一年级~六年级全覆盖）。
- **语文**：看词语选拼音（四选一，附词义）；**英语**：英↔中四选一。
- **家长 PIN / 卸载密码**：PBKDF2 派生哈希存储，连续失败触发冷却。
- **使用统计 + 临时加时/暂停**：显示今日已用；家长可"本次 +15 分钟"或"暂停/继续计时"。
- **防绕过**：进程 DACL 自保护（拒绝结束/挂起/改 DAC）、锁屏期间禁用任务管理器、低级键盘钩子（屏蔽 Win/Alt+Tab/Ctrl+Esc 等）、每 500ms 置顶抢焦点、屏蔽系统关闭/最小化/任务栏命令。
- **守护与自启**：看门狗进程在看门狗被杀时重启、主程序被杀且处于锁屏标记时重启并保持锁屏；开机自启（计划任务最高权限，无 UAC 弹窗，失败回退 HKLM Run）。
- **重启仍锁 / 断电折算**：锁屏标记持久化，重启后继续锁；硬断电按 UTC 墙钟折算扣除离线时长，防止"断电冻结倒计时"。
- **程序图标**：任务栏托盘图标、设置窗口标题栏、exe 本体图标。
- **关于窗口**：声明免费、作者 bgaidu、AI，并显示版本号。

## 四、核心机制详解

### 4.1 倒计时与持久化
- 剩余秒数 `remaining` 每秒递减；每 `PersistIntervalSec`(15s) 写回注册表 `RemainingSeconds` 与 `LastSeenUtc`（UTC Ticks）。
- 改系统时间、重启均无法重置倒计时（以 UTC 墙钟为准）。

### 4.2 按用户分别限制
- 维度：当前 Windows 登录用户名 `Environment.UserName`。
- 注册表按用户键：`U:<user>:<field>`（`Dur` 时长、`Win` 时段、`UsedDate/UsedSec` 统计、`Grades` 多选年级、`Subjects` 多选科目）。
- 读取时优先用户值 → 回退全局默认 → 再回退内置默认。

### 4.3 锁屏触发与解锁
- **触发源**：① 时长到点；② 不在每日可用时段（硬锁）；③ 托盘"立即锁定"/开机带锁标记。
- **硬锁（时段外）**：禁用答题，仅家长 PIN 或"进入允许时段自动解锁"，期间不计时不扣时长。
- **答题解锁**：10 题全对即解锁并开始新一轮计时；答错整批清零 + 冷却 5 秒。
- **家长入口**：锁屏界面"家长入口"→ 输家长 PIN 解锁（PIN 连续 5 次失败冷却 30 秒）。

### 4.4 断电折算（DeductOffline）
- 正常关机/重启会清 `LastSeenUtc`，下次开机不扣离线时长。
- 硬断电收不到事件：下次开机按 `UtcNow - LastSeenUtc` 折算扣除；离线 < 30 秒视为正常关机不扣；时钟回拨不扣（防止加时）。

### 4.5 看门狗与守护
- 看门狗进程（`--watchdog`）轮询主进程；主被杀且 `LockFlag=1` 则重启主程序并保持锁屏。
- 主程序 `guardThread` 每 3s 检查看门狗是否存活，被杀则重启；锁屏期间持续确保任务管理器被禁用。
- 正常退出经 `StopEvent` 通知看门狗自行退出。

### 4.6 开机自启
- 优先创建计划任务 `PCLock`（登录时运行、最高权限、延迟 30 秒，无 UAC 弹窗）；失败回退 HKLM `...\Run`。

### 4.7 自保护与任务管理器
- `Protection.ProtectSelf`：给进程设置 DACL，对 Everyone **拒绝** TERMINATE / WRITE_DAC / SUSPEND_RESUME 等，任务管理器/taskkill 结束会"拒绝访问"。
- 锁屏期间 `SetTaskMgrDisabled(true)`：写 `DisableTaskMgr=1`（HKCU + HKLM 双保险）；解锁/退出恢复。

### 4.8 卸载清理
- 校验卸载密码 → 恢复 DACL/任务管理器 → `Store.RemoveAll`（删注册表键）→ 删计划任务 → 延时删除程序目录（`rd /s /q`）。

## 五、数据存储设计（注册表）

根键：`HKLM\SOFTWARE\PCLock`（需管理员）

| 值名 | 类型 | 含义 | 默认 |
|---|---|---|---|
| `FirstRunDone` | DWORD | 是否已初始化 | 0/1 |
| `PinHash` | 字符串 | 家长 PIN 哈希（`pbkdf2$iter$salt$hash`） | 1234 的哈希 |
| `UnPinHash` | 字符串 | 卸载密码哈希 | 1234 的哈希 |
| `DurationMinutes` | DWORD | 全局默认时长（回退用） | 60 |
| `Grade` / `Subject` | DWORD | 旧版全局单值年级/科目（兼容保留） | 3 / 0 |
| `LockFlag` | DWORD | 是否处于锁屏（重启仍锁） | 0 |
| `RemainingSeconds` | DWORD | 剩余秒数 | -1/时长 |
| `LastSeenUtc` | QWORD | 上次写入剩余时的 UTC Ticks | 0 |
| `U:<user>:Dur` | DWORD | 该用户时长 | — |
| `U:<user>:Win` | 字符串 | 该用户可用时段 | 空=全天 |
| `U:<user>:Grades` | 字符串 | 该用户多选年级，如 `1,3,5` | 空=全选 |
| `U:<user>:Subjects` | 字符串 | 该用户多选科目，如 `1,2` | 空=三科 |
| `U:<user>:UsedDate` / `UsedSec` | 字符串/DWORD | 今日已用统计 | — |

> PIN 使用 PBKDF2（迭代 25000 次）加盐哈希，验证成功后将旧格式自动升级；卸载/退出均不保存明文。

## 六、题库设计与自定义

### 6.1 数学（动态生成，答案恒为整数）
按年级课标计算要求生成，各年级题型：

| 年级 | 题型 |
|---|---|
| 一 | 10 以内加减、20 以内进位加/退位减、连加连减、加减混合 |
| 二 | 100 以内进位加/退位减、表内乘除、连减 |
| 三 | 两/三位数×一位数、三位数÷一位数（整除，含商中间/末尾为 0）、四则混合(小括号)、同分母分数加减、一位小数加减 |
| 四 | 三位数×两位数、除数是两位数、四则运算(含中括号)、运算律简便(25×4/125×8/分配律等) |
| 五 | 小数乘除、分数乘除、异分母分数加减、最大公因数/最小公倍数 |
| 六 | 分数/小数除法、百分数及互化、两三步混合、长方体/正方体体积与表面积、圆(π取3.14)、行程、公因数/公倍数 |

> 因答案框仅接受数字，分数/小数题都设计为**整数结果**。多选年级时，数学题在选中年级中随机抽取难度。

### 6.2 语文/英语（词库 + 外部文件）
- 程序目录下的 `chinese.txt` / `english.txt` **优先**；缺失或为空则回退内置兜底题库（永不空库）。
- 必须保存为 **UTF-8** 编码。

**语文 `chinese.txt`**：`年级|词语|拼音|释义`
```
1|太阳|tài yáng|恒星，白天发光发热的天体。
3|观察|guān chá|仔细察看事物或现象。
```

**英语 `english.txt`**：`年级|英文单词|中文意思`
```
1|apple|苹果
5|curious|好奇的
```

- 家长可直接用记事本编辑这两个文件增删词条（保持格式与 UTF-8），保存后**下次锁屏**生效。

## 九、使用说明

### 9.1 安装 / 部署
1. 确保已安装 **.NET Framework 4.0+**（Win10/11 默认已有；Win7 可能需安装）。
2. 用 `build.bat Release` 构建，取 `bin\Release\` 整个目录（含 `PCLock.exe`、`PCLock.exe.config`、`chinese.txt`、`english.txt`、`AppIcon.ico`）放到目标机器，或直接在本机构建后运行。
3. **首次运行请允许管理员权限**（UAC 弹窗选"是"）——程序需要写 HKLM/策略/计划任务。

### 9.2 首次运行
- 双击 `PCLock.exe`，托盘出现盾形图标，开始倒计时（默认 60 分钟）。
- 默认家长 PIN 与卸载密码均为 `1234`，请尽快在"家长设置"中修改。

### 9.3 家长设置（托盘右键 →"设置…"，需家长 PIN）
| 分区 | 说明 |
|---|---|
| 配置对象 | 选择要为哪个 Windows 用户设置（下方各项均按该用户生效） |
| 每次可用时长 | 选 15/30/45/60/90/120 分，点"保存时长" |

### 9.4 日常使用与锁屏/解锁
- 正常使用时托盘显示"剩余 X 分 X 秒"；最后 5 分钟 / 1 分钟有托盘气泡提醒（渐进遮罩已移除，不再有屏幕渐暗）。
- 到点或不在时段内即全屏锁屏：
  - **答题解锁**：依次答对 10 题（数学填数字，语文/英语四选一）；答错清零重来并冷却 5 秒。
  - **家长解锁**：点右下角"家长入口"输 PIN。
- 时段外为硬锁：只能家长 PIN 或等到允许时段开始自动解锁。

### 9.5 临时加时 / 暂停
- 家长设置里"本次 +15 分钟"临时增加本次会话时长；"暂停计时"后孩子仍可用电脑但不再倒计时（再点"继续计时"恢复）。

### 9.6 自定义题库
- 用记事本打开程序目录下的 `chinese.txt`/`english.txt`，按格式增删，保存为 UTF-8；下次锁屏生效。删除文件则回退内置题库。

### 9.7 退出 / 卸载
- **退出程序**：家长设置 →"退出程序"（本次不计时，下次开机重新开始；会先校验是否继续）。
- **卸载并删除程序**：家长设置 →"卸载并删除程序" → 输入卸载密码 → 自动清理注册表、计划任务并删除程序目录。

### 9.8 常见问题（FAQ）
- **Q：为什么需要管理员权限？** A：要写 HKLM 注册表、系统策略与计划任务以实现跨用户限制和开机自启。
- **Q：锁屏时想打开任务管理器？** A：锁屏期间已禁用任务管理器（防绕过）；解锁后自动恢复。
- **Q：改系统时间能多玩吗？** A：不能。倒计时以 UTC 墙钟为准并定期持久化，改时间/重启都无法重置。
- **Q：断电/直接关机？** A：正常关机不扣离线时长；硬断电会按离线时长折算扣除（防止冻结倒计时）。
- **Q：忘记家长/卸载 PIN？** A：可删除注册表 `HKLM\SOFTWARE\PCLock` 下的 `PinHash`/`UnPinHash` 后重启即恢复默认 `1234`（需管理员）。
- **Q：托盘图标不见了/程序没在？** A：看门狗会尝试重启；也可检查计划任务是否被删。

## 十、安全与限制说明

- **PIN 安全**：PBKDF2（25000 次迭代）加盐哈希存储，锁屏/PIN 输入框仅接受数字，连续 5 次失败冷却 30 秒，降低离线枚举风险。
- **防绕过强度**：DACL 拒结束/挂起 + 禁任务管理器 + 键盘钩子 + 强制置顶 + 屏蔽系统命令，可抵御常见的任务管理器结束、快捷键切换、最小化等操作。
- **已知边界（诚实说明）**：任何纯软件家长控制都无法"绝对"防止具备管理员权限的用户绕过——例如重装系统、进入安全模式、用 PE/其他管理员账户删除计划任务与注册表、或直接禁用/删除程序。本程序面向"防止孩子在日常使用中轻易绕过"，不构成对抗高权限用户的绝对屏障。如需更强约束，请配合系统账户权限与 BIOS/磁盘加密等措施。
- **数据位置**：配置在注册表（HKLM），日志 `err.txt`/`watchdog_log.txt` 在程序目录；均不上传、不联网。

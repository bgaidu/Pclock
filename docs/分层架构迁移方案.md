## 目标结构

```
src/
├── Host/            L0  Program.cs（启动编排、异常钩子、单实例、--watchdog/--updater 分发）
├── Core/            L2  纯逻辑，无 WinForms / 无注册表，可 100% 单测
│   ├── SessionTimer.cs      倒计时与离线折算
│   ├── TimeWindow.cs        时段/多规则判定
│   ├── QuestionEngine.cs    题库与出题
│   ├── PinHasher.cs         哈希
│   ├── LearningPolicy.cs    SM-2 / 加练池 / 星级 / 难度加权
│   └── BankQuality.cs       题库门禁
├── Platform/        L1  系统集成，依赖 Win32/注册表，接口可 mock
│   ├── RegistryStore.cs
│   ├── StartupManager.cs
│   ├── SelfProtection.cs    ← DACL 字节布局，高风险，不重写只搬
│   ├── WatchdogHost.cs
│   ├── PowerEventBridge.cs
│   └── AuditLog.cs
├── UI/              L3  LockForm / SettingsForm / AdvancedSettingsForm /
│                        PracticeForm / UsageForm / FirstRunForm / PinDialog
└── CrossCutting/    Constants / Strings / AppVersion / ConfigIo / BankIo
```

约束：`Core` 不得引用 `Host`（现有 `Store.SetLogSink` 注入已解决一次同类问题）；
`Platform` 通过接口暴露，便于单测注入假实现；`SelfProtection` 只移动文件不改字节构造逻辑。

## 迁移顺序（每批都必须跑 `tests\gate.bat` + 真机 B 清单）

1. **先建目录与命名空间，不移动代码**：新增 `Core/` 空目录与项目约定文档，
   `build.bat` 通配 `src\*.cs` 需改为递归收集（`for /R src %%f in (*.cs)`），
   `tests\run.bat` 显式清单同步登记；`PCLock.csproj` 已用 `src\**\*.cs` 通配，天然兼容。
2. **搬纯逻辑**：`Policy.cs` → `TimeWindow.cs`；`Learning.cs` → `LearningPolicy.cs`；
   `QuestionPolicy.cs` → `BankQuality.cs`；`Questions.cs` 拆出题引擎与题库数据。
   保持 `namespace PCLock` 不变（避免一次性改所有 using），只改物理路径。
3. **搬平台层**：`Store.cs`/`Store.Extras.cs` → `RegistryStore.cs`；
   `Protection.cs` 整体搬运、**不改一个字节**；`StartupManager.cs`、`Watchdog.cs` 跟随。
4. **搬 UI 与宿主**：UI 文件进 `UI/`；`Program.cs` 进 `Host/`。
5. **最后才拆接口**：给 `Platform` 抽 `IStore` / `IProtection` / `IClock`，
   让 `Core` 的会话逻辑可在纯 JVM/CLR 单测里跑，不依赖管理员权限。

## 风险与验收

| 风险 | 缓解 |
|---|---|
| `build.bat` 的 `for %%f in (src\*.cs)` 不递归，搬目录后全部源文件找不到（历史上已踩过 CS2001） | 第 1 批先改递归收集，用 `dir /s /b src\*.cs` 核对数量后再搬文件 |
| `tests\run.bat` 显式清单漏登记 → 测试编译失败或悄悄少测 | 每批把新路径写进清单，并在 `gate.bat` 增加「源文件数量与清单一致」检查 |
| DACL 字节布局被误改 | `Protection.cs` 用 `git mv` 原样搬运，diff 必须只有路径变化 |
| 双进程互守护路径依赖 `Application.ExecutablePath`，搬动不影响 | 每批真机验证 B7/B8/B9（杀进程、看门狗互拉、卸载无残留） |
| 回归清单未跑完就大改 | 迁移前置条件：B1–B43 全部 PASS，签名表完整 |

## 验收标准

- `tests\gate.bat` 全绿，单测数量不减少；
- `build.bat Release|Debug`、`build_msbuild.bat` 双通道均成功；
- 产物时间戳为当次，文件数与迁移前一致（无源文件丢失）；
- 真机 B1–B43 逐项重跑全 PASS，尤其 B7/B8/B9/B15/B16。
